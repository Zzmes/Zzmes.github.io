在 Ubuntu Server 上配置 Clash：让终端代理随开机启动

本文最后更新于：2026年10月31日 下午

给 Ubuntu Server 配置代理时，启动 Clash 只是第一步。要让终端里的工具使用它，还需要设置代理地址；想在重启后继续使用，则要把 Clash 交给 systemd 管理。

这篇把这几步串起来：先手动跑通，再配置终端开关，最后设置开机自启。后面需要换配置或排查连接问题时，也能顺着同一条线检查。

遇到问题时，我会依次检查三个地方：服务有没有运行、代理端口能不能访问、当前应用有没有使用正确的代理地址。把这三件事分开确认，通常比反复改配置更容易定位原因。
